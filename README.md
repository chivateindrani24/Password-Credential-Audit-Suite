# Password Credential Audit Suite

## Overview

A cybersecurity project developed in Kali Linux for password security assessment and auditing.

## Features

- Dictionary Generator
- Hash Analysis
- Password Strength Analyzer
- Brute Force Simulation
- Security Audit Reporting

## Technologies

- Python
- Kali Linux
- Git & GitHub

## Educational Purpose

This project is designed for ethical cybersecurity education and password security awareness.
